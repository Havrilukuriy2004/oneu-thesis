==============================================

Що в папці
  *.R                      — увесь код (01–08, utils_*, run_all_v6.R)
  data_nbu/parquet/        — база даних: raw_* (НБУ: OSB, фінзвітність, MIR, депозити, КЛК, ліквідність,
                             інфляція, ключові ставки) + local_*_params (криві ОВДП), кожна таблиця у двох
                             форматах: .parquet (якщо встановлено arrow) і .rds (запасний варіант)
  data_nbu/local_inputs/   — файли з сайту НБУ, оновлюєте вручну:
                             UIRD.xls, 5-7-9.xlsx,
                             4-Financial_markets.xlsx (повна статистика процентних ставок, розділ 4),
                             Surveys_price.xlsx (інфляційні очікування), Surveys_rate.xlsx (курсові очікування),
                             BLS_*.xlsx (опитування про умови банківського кредитування),
                             07_Surveys_Expectations.xlsx (запасне джерело ІОДА/квартального опитування підприємств),
                             UONIA_money_market.xlsx («Грошовий ринок: динаміка UONIA»; API NBU_uonia віддає HTTP 500)
  output_nbu/              — з'явиться після запуску (таблиці, рисунки, Excel, Word)

1) Один раз: встановити R (https://cran.r-project.org/bin/macosx/ — версія для Apple silicon, arm64)
   і RStudio (https://posit.co/download/rstudio-desktop/).
2) Один раз: відкрити в RStudio 00_install_packages.R і натиснути Source.
3) Відкрити run_all_v6.R і натиснути Source (або в консолі:
     setwd("~/Documents/master_thesis_section2"); source("run_all_v6.R", encoding = "UTF-8")
   ).
   Прапорці на початку run_all_v6.R:
     UPDATE_DB <- TRUE   завантажить з НБУ нові місяці (потрібен інтернет); FALSE — працювати лише з наявною базою
     FILL_GAPS <- TRUE   (разом з UPDATE_DB <- FALSE) — лише дозаповнити пропуски всередині рядів, без повного оновлення
     CHECK_DB  <- TRUE   перевірка бази -> output_nbu/logs/db_check_v6.csv
     BUILD     <- TRUE   перебудувати марти (обов'язково при першому запуску)
     MODELS    <- c("03","04","05","06","07","09","08")
   Порядок: 01 (оновлення) -> 01b (перевірка) -> 02 (марти) -> 03–05 (2.1) -> 06 (динаміка) -> 07 (2.2)
            -> 09 (очікування агентів, повна статистика ставок, грошова статистика) -> 08 (таблиці Word, завжди останнім).
   Час: 02 ~1–2 хв, 03–06 ~5 хв, 07 ~6–15 хв (Марков — найдовше), 08 ~10 с.

Пропуск MIR 2023-03…2024-05
  У базі немає 15 місяців статистики процентних ставок за новими кредитами й депозитами (raw_mir).
  Звичайне оновлення бере лише останні місяці, тому дірку всередині ряду не латало. Тепер 01 (і окремо 01c)
  знаходить пропущені місяці в кожній місячній таблиці й перезавантажує саме їх з API НБУ.
  Звіт: output_nbu/logs/db_gaps_v6.csv (rows_found, months_filled, still_missing).
  Якщо still_missing > 0 — НБУ не віддає ці місяці через API; тоді потрібен xlsx зі статистики процентних ставок НБУ.

Примітки
  * База в папці — знімок, що закінчується 08–09.2026. З UPDATE_DB = TRUE код сам дозавантажить нові місяці
    (і перезавантажить останні 3 місяці через можливі уточнення НБУ).
  * Якщо arrow не встановився — нічого страшного: код читає/пише .rds. Якщо згодом встановите arrow,
    один раз запустіть з UPDATE_DB = TRUE і BUILD = TRUE, щоб .parquet знову стали актуальними.
  * Шрифт рисунків і таблиць — Times New Roman (є в macOS). Інший: Sys.setenv(THESIS_FIG_FONT = "Arial") перед запуском.
  * Шлях до папки визначається автоматично (за розташуванням run_all_v6.R); папку можна переносити.

Очікування економічних агентів і грошова статистика (04.11.2026)

  ставки, очікувану девальвацію, надлишкову дохідність гривневого депозиту (UIP), ринкову очікувану зміну облікової
  (крива ОВДП), BLS (попит, стандарти), ІОДА, грошові агрегати M0–M3, доларизацію, частку строкових депозитів.
  07: облікова ставка розкладена на очікувану й несподівану складові (P13a); панельні LP для обох складових;
      стійкість із контролем очікувань і з несподіваним шоком; системні ряди Маркова — за статистикою НБУ (гривня).

      кредит: попит vs пропозиція (BLS, ІОДА), режими Маркова vs очікування, грошова трансмісія.
